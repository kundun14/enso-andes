# ENSO-ANDES (ENSO-DSSAT-ANDES)

Sitio web del proyecto **Evaluación del impacto del fenómeno El Niño-Oscilación del Sur (ENSO) en la productividad de los cultivos de papa y maíz** (Concurso CONCYTEC–PROCIENCIA E041-2027-03), publicado en GitHub Pages:

`https://kundun14.github.io/enso-andes/`

## Estructura

- `index.html`, `css/styles.css`, `js/main.js`: Landing page principal con resumen, paquetes de trabajo por objetivos (OE 1–3 + transversal), metodología, resultados esperados y consorcio (**UNALM**, **UNSAAC**, **CIP**).
- `assets/enso-andes-logo.png`: Emblema ilustrado estilo dibujo a mano del proyecto.
- `assets/consorcio/`: Logos institucionales (`molina.jpg`, `unsaac.jpg`, `cip.jpg`).
- `docs-quarto/`: Documentación técnica y cronograma compilados automáticamente con **Quarto** vía `.github/workflows/deploy.yml`.
